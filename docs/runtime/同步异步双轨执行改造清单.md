# 同步 / 异步双轨执行改造清单

> 目标：保留 sync 能力，补齐 async 主路径，使 MCP 可正确执行。  
> 原则：双轨并存；调用方选型；禁止在 sync 路径用 `asyncio.run(ainvoke)` 冒充兼容。

---

## 0. 设计约定

- [ ] **双轨 API 对照表**写入模块文档（Agent / Strategy / Node / Tool）
- [ ] 约定：仅本地 `FUNCTION` 可用同步轨；含 `ToolType.MCP` 必须走异步轨
- [ ] 约定：混用 registry 时以最严需求为准（有 MCP → 整次调用走 async）
- [ ] 明确禁止：sync `execute` / `invoke` 内 `asyncio.run(handler.ainvoke(...))`

| 层级 | 同步轨 | 异步轨 |
|------|--------|--------|
| Agent | `invoke` / `stream` | `ainvoke` / `astream` |
| Strategy | `invoke` | `ainvoke` |
| Node | `run` | `arun` |
| ToolExecutor | `execute` → `handler.invoke` | `aexecute` → `handler.ainvoke` |
| Graph | `graph.invoke` | `graph.ainvoke` |

## 1. PR1 — 打通异步轨（不拆同步轨）

### 1.1 Node

- [ ] `Node` 契约：保留 `run`，新增/补齐 `arun`
- [ ] 已有 sync 节点：`arun` 默认包装 `return self.run(...)`（过渡）
- [ ] `ToolNode.run` → `execute`（本地 sync，保留）
- [ ] `ToolNode.arun` → `aexecute`（MCP 主路径，已有则接到图）

### 1.2 Graph

- [ ] `Graph.build`：节点注册支持 async（挂 `node.arun` 或双轨 Runnable）
- [ ] 文档写明：含 MCP 时必须 `ainvoke`，不以 sync `invoke` 跑 MCP

### 1.3 Agent / Strategy

- [ ] `Agent.ainvoke` → `compiled_graph.ainvoke`
- [ ] `Agent.astream` → `compiled_graph.astream`
- [ ] `Agent.aresume`（与 `resume` 对称，可选同 PR）
- [ ] 保留现有 `invoke` / `stream` / `resume`
- [ ] `BaseStrategy` / `ReActStrategy`：保留 `invoke`，新增 `ainvoke`
- [ ] `ReActNode`：保留 `run`，新增 `arun` → `await strategy.ainvoke`

### 1.4 测试

- [ ] `tests/test_react_agent_mcp.py` 改为 `await agent.ainvoke` / async stream
- [ ] `tests/test_react_agent.py` 保持 sync `invoke`（验证同步轨未破坏）
- [ ] 复测 MCP Case：`先把 7 和 8 相加，再 echo` → 工具 `success=True`，无 `StructuredTool does not support sync invocation`
